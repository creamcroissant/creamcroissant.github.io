申请 Let's Encrypt 公网 IP 证书并部署至 Caddy

John Doe
2026-03-31
运维
Caddy, IP证书, Let's Encrypt, SSL, acme.sh

Let’s Encrypt 支持通过 shortlived（短期证书，有效期 6 天）配置文件为公网 IP 申请可信的 SSL 证书。本文提供两种实现方案：Caddy 原生自动托管（首选） 与 acme.sh 独立申请 + Caddy 部署（备选）。

方案一：高版本 Caddy 原生自动托管（极简推荐）

原生自动托管要求 Caddy 版本 >= v2.10.0。由于系统默认 apt 源的 Caddy 版本通常较老，必须先配置官方源进行安装或升级。
